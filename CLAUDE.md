# JARVIS-AGENT: rules for Claude Code

This repo is worked on by two agents at the same time: Claude Code (terminal, SSH, deploys) and Cursor (IDE). The user wants every existing feature working; nothing gets removed.

- The shared plan is `plan.md`. Claude takes only `C-` tasks. Cursor takes `X-` tasks.
- Lanes (`plan.md` section 2.1; machine-readable copy `.coord/lanes.json`, enforced by the pre-commit hook; `python scripts/coord/check_lane.py --whoowns <path>` prints a path's owner):
  - **Claude:** `src/core/**`, `services/ai_core/**`, `services/utils/**`, `deploy/**`, `scripts/**`, root config (`requirements*.txt`, `pyproject.toml`, `pytest.ini`, `.env*`, `Dockerfile*`, `docker-compose.yml`, `main.py`, `.gitignore`, `.githooks/**`, `.github/**`, `.coord/**`; full list in `.coord/lanes.json`), `CLAUDE.md`, `.cursor/rules/**`, `docs/**`, `README.md`, `tests/core|unit|infrastructure|integration|vision|exhaustive/**`, `tests/conftest.py` and the other `tests/*.py`, and everything on the VPS.
  - **Cursor:** `stonix_ui/**` (frontend + Electron), `services/automation/**`, `services/info/**`, `services/multimedia/**`, `services/system/**`, `assets/**`, `tests/automation/**`, `tests/scripts/**`, `tests/tools/**`, `tests/test_reminders.py`, `tests/test_whatsapp.py`.
  - **Shared:** `plan.md` (only your own task status lines and section 11 "Handoff") and `done_highlight.md` (append-only: add at the end, never edit or remove a line).

  Don't edit Cursor-lane files; write a request in `plan.md` section 11 instead.
- Claim a task with `DOING (claude, <date time PKT>)` on its status line. Append each finished task at the end of `done_highlight.md` using that file's template; never edit, reorder or remove an existing line (the hook rejects it).
- Git: commit only your own files, with `JARVIS_AGENT` set and an explicit pathspec: `git add <your new files>`, then `JARVIS_AGENT=<claude|cursor> git commit -m "[<claude|cursor>] <TASK-ID>: <summary>" -- <your paths>` (PowerShell: `$env:JARVIS_AGENT='cursor'; git commit -m "[cursor] X-NN: <summary>" -- <your paths>`). Claude adds the `Co-Authored-By` trailer. The pre-commit hook (`scripts/coord/precommit.py`) rejects a missing `JARVIS_AGENT`, paths outside your lane, secret files and values, private terms and removed or changed `done_highlight.md` lines; never bypass it with `--no-verify`. Only Claude pushes to `origin main` (github.com/Matloob11/JARVIS-AGENT, never forced); Cursor never pushes. Never `git add -A`, stash, hard reset, clean, checkout another branch, or force push, because Cursor works in the same working tree.
- VPS 187.127.123.235: only Claude changes it. Back up first. Touch only Docker project `jarvis` and `/etc/nginx/conf.d/jarvis.conf`. Other apps on that server must keep working.
- Only one Windows agent worker may run. Respect the `RUNTIME LOCK` line in `plan.md` section 2.6.
- The GitHub repo is public: never print, paste or commit secrets from `.env` files, and keep secrets, passwords, keys, voice samples, logs, chat data and details of non-JARVIS apps or servers out of tracked files (code, docs, `plan.md`, `done_highlight.md`) and commit messages.
- Contracts: read `docs/CONTRACTS.md` (canonical; `plan.md` section 4 is a copy) before touching any API, socket event, LiveKit topic, env name or schema. A change is requested as `REQ-CONTRACT <contract> <proposal>` in `plan.md` section 11; only Claude edits `docs/CONTRACTS.md` (new version + Changelog line, and the copy in `plan.md` section 4).
